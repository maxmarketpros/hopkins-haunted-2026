# Hopkins Haunted Attraction — website

The 2026 site for [hopkinshauntedattraction.com](https://www.hopkinshauntedattraction.com): a static Next.js 16 + Tailwind v4 build deployed on Netlify. It replaces the Wix site. `PLAN.md` holds the content inventory and design system.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

For Netlify-accurate behaviour locally (image CDN, redirects, forms):

```bash
npm run build      # writes out/
npx netlify serve  # http://localhost:8888
```

## Where things live

| What | Where |
|---|---|
| Dates, hours, prices, characters, FAQ, crew copy, contact, links | `src/content/site.ts` |
| Blog posts | `content/blog/*.mdx` (front matter + Markdown) |
| Pages | `src/app/<route>/page.tsx` |
| Design tokens (colors, type, utilities) | `src/app/globals.css` |
| Redirects from old Wix URLs, cache headers | `netlify.toml` |
| Images, video, OG images | `public/` (generated by the scripts below) |

## Yearly updates

**New season dates or prices:** edit `season.nights`, `season.dateGroups`, `season.hoursLine` and `passes` in `src/content/site.ts`. The countdown, date grid, JSON-LD events and every mention on the site read from there.

**Add or edit a character:** add an entry to `cast` in `src/content/site.ts` and drop a 900×1200 WebP in `public/images/cast/`. The characters page, its detail routes and the sitemap update automatically. `descriptor` and `spottedAt` are editable copy.

**Next tryout date:** set `crew.tryouts.nextDate` (a string) in `src/content/site.ts`. While it is `null` the call sheet says "To be announced".

**New blog post:** copy an existing file in `content/blog/`, change the front matter (`title`, `description`, `excerpt`, `date`, `author`, `cover`, `coverAlt`) and write Markdown below it. Put the cover in `public/images/blog/`. The file name is the URL slug.

## Asset pipeline (already run; re-run only if sources change)

```bash
node scripts/fetch-assets.mjs     # downloads the originals from the old Wix site into raw/ (gitignored)
node scripts/optimize-images.mjs  # raw/ → public/ as WebP/PNG + blur placeholders (src/content/blur.json)
node scripts/transcode-video.mjs  # raw/video → public/video (hero loop + trailer), needs ffmpeg
node scripts/build-og.mjs         # OG images per page, app icons, favicon
node scripts/extract-blog.mjs     # migrates the four Wix posts into content/blog/
```

Generated photos in `public/images/generated/` were made with Codex image generation (prompts in `PLAN.md`).

## Deploy on Netlify

1. Push this repo to GitHub.
2. Netlify → **Add new project → Import from Git**. Build settings are read from `netlify.toml` (`npm run build`, publish `out`).
3. Every push to `main` deploys; pull requests get preview URLs.
4. **Forms:** the contact form is detected automatically at deploy. Turn on email notifications in Netlify → Forms.
5. **Domain:** add `www.hopkinshauntedattraction.com` as the primary domain and `hopkinshauntedattraction.com` as a redirect. In Wix, point DNS at Netlify (A `@` → `75.2.60.5`, CNAME `www` → `<site>.netlify.app`) or move nameservers to Netlify DNS. HTTPS is automatic once DNS resolves. Keep Wix live until the new site answers on the domain, then cancel it.
6. Optional: add `hopkinshauntedhayride.com` as a domain alias so the old 2025 domain forwards here.

## Notes

- `next/image` is routed through Netlify Image CDN via `src/lib/image-loader.ts`; in `next dev` images are served as-is.
- The hero video is muted and skipped for visitors with reduced-motion or data-saver on. The trailer plays with sound on click.
- Old Wix URLs (`/about-hopkins-haunted-attraction`, `/post/<slug>`, etc.) 301 to the new pages. See `netlify.toml`.
